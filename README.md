# Floristería Flora - Catálogo Web Mobile-First

Catálogo web optimizado para móvil de **Floristería Flora**, situada en C. Muyay, 130, Arrecife (Lanzarote).

## Características

- **Mobile-First**: Diseño optimizado exclusivamente para dispositivos móviles
- **Catálogo Visual**: Galería estilo carrusel deslizable con imágenes optimizadas de ramos
- **Categorías**: Ramos para ocasiones especiales (Cumpleaños, Eventos, Condolencias)
- **Precios visibles**: Cada ramo muestra su precio
- **Encargo directo**: Botón inferior fijo "Encargar Ramo por WhatsApp" que abre un chat directo con mensaje predefinido
- **Información de entregas**: Sección sobre entregas a domicilio en Arrecife y alrededores
- **Swipe táctil**: Soporte para deslizar con el dedo en móviles
- **Diseño atractivo**: Paleta en tonos rojos/rosa acorde a una floristería

## Tecnologías

- HTML5
- CSS3 (Mobile-first, variables CSS, Flexbox, Grid)
- JavaScript vanilla (Carrusel interactivo + integración WhatsApp)

## Cómo visualizar la web

### Opción 1: Abrir localmente
1. Descarga o clona este repositorio
2. Abre el archivo `index.html` en tu navegador móvil o con las herramientas de desarrollador en modo responsive

### Opción 2: GitHub Pages (Recomendado)
Una vez publicado en GitHub, la web estará disponible en:
`https://[tu-usuario].github.io/[nombre-repositorio]/`

Para habilitar GitHub Pages:
1. Ve a Settings > Pages en tu repositorio de GitHub
2. En "Source", selecciona `Deploy from a branch`
3. En "Branch", selecciona `main` (o `master`) y carpeta `/ (root)`
4. Pulsa Save
5. Espera unos minutos y accede a la URL proporcionada
